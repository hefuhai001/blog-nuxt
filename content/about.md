## 这个站点是做什么的

CodeTrail（代码轨迹）是我的个人技术博客，主要记录后端开发与工程实践中的真实经验：环境搭建、框架使用、部署运维，以及那些文档里不会告诉你的坑。

内容以 **Django**、**Docker**、**数据库**、**日常开发工具** 为主，所有文章都来自实际项目中的踩坑与复盘，力求每篇都能直接照着做、用得上。

## 为什么叫「代码轨迹」

写代码就像走夜路，每一步踩过的坑都值得留下标记。这个站存在的意义，就是把个人的调试过程、配置片段和解决方案沉淀成一条可回溯的轨迹——既是写给未来的自己，也希望照亮同路人的下一段路。

## 关于内容

- **实用优先**：少讲概念，多给可以直接复制的配置和命令
- **真实场景**：每篇文章都对应一个实际遇到的问题，而不是教程的搬运
- **持续修订**：发现旧的结论过时会回头更新，评论区欢迎指正

## 技术实现

本站使用 Nuxt 4 + Nuxt Content 构建，样式基于 Tailwind CSS v4，文章以 Markdown 编写、Git 管理，支持暗色模式、全文搜索与 PWA 安装。评论系统基于 Giscus，由 GitHub Discussions 驱动。
